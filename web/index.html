Good to know
Does it count steps in the background?

Web apps can't run motion sensors when closed or when the phone is locked — that's an Android limitation, not a Chaal one. Keep Chaal open (it holds your screen on during workouts) and it counts everything. For 24/7 background counting you'd need a native app like Google Fit.

Where is my data?

Only on this phone, in the app's private storage. There is no server, no account, nothing uploaded. Export a JSON backup any time.

Why does step counting need the screen on?

Android pauses sensor access for web pages when the screen turns off. During workouts Chaal requests a wake lock so the screen stays on.

How accurate is it?

Step counting uses peak detection on the accelerometer — good for walking and running, roughly ±10%. GPS distance is accurate outdoors with a clear sky. Calorie numbers are estimates.
